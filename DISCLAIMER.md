## API Key and Credential Responsibility

GenAI Systems Lab follows a strict **Bring Your Own Key (BYOK)** model. API keys are provided per request via the `X-API-Key` header and are never stored persistently — synchronous keys are request-scoped and never written to disk; queued-job keys are Fernet-encrypted in Redis with a one-hour expiry and are deleted when consumed.

Even so:

- You are responsible for keeping your API keys secure.
- Never commit populated `.env` files, JWT secrets, or encryption keys to version control.
- You are responsible for any usage charges your API keys incur.
- The maintainer accepts no responsibility for unauthorized use of your credentials.

## Generated Code Execution

The `lg-debugging-agent` project executes Python code generated by a language model. This is an **unsafe, trusted-local experiment** and is excluded from all shared execution surfaces by default. It can only be enabled with `GENAI_SYSTEMS_LAB_ENABLE_UNSAFE_AGENTS=true` and only when `APP_ENV` is not `prod`. You accept full responsibility for enabling and using this feature.
